# Internationalisation (i18n)

## Languages

`en` (default), `si` (Sinhala), `ta` (Tamil). In code this is the enum `com.suwalink.entity.Language`
(`EN, SI, TA`); JSON and the database always use the lowercase code (`"en"`, `"si"`, `"ta"`).

- Each user has `preferred_language` (default `en`) and an optional `district`, set with
  `PUT /api/users/me/preferences` (`{"preferredLanguage":"si","district":"KANDY"}`) and returned by `GET /api/users/me`.
- Request locale: `Accept-Language` (`en`, `si`, `ta`; anything else falls back to `en`) via `AcceptHeaderLocaleResolver`.
- Message bundles: `backend/src/main/resources/i18n/messages.properties` (en), `messages_si.properties`,
  `messages_ta.properties`; `MessageSource` basename `i18n/messages`, UTF-8, no system-locale fallback.
  Every key must exist in all three files (enforced by `UserPreferencesTest`).

## API error codes

API error `message` stays English. The frontend translates the stable `code`
(and `errors[].code` for field errors, which is the constraint annotation name, e.g. `NotBlank`, `Size`, `AssertTrue`).
Bundle keys are `error.<code in lowercase>`.

| code | typical status | meaning |
|---|---|---|
| VALIDATION_FAILED | 400 | bean validation or invalid request content |
| MALFORMED_REQUEST | 400 | unreadable body or unknown enum value (e.g. language `fr`) |
| INVALID_PARAMETER | 400 | bad path/query parameter |
| NOT_FOUND | 404 | resource missing |
| ACCESS_DENIED | 403 | not allowed |
| UNAUTHENTICATED | 401 | bad credentials |
| DUPLICATE | 409 | already exists (incl. second response to a prescription request) |
| EMAIL_TAKEN | 409 | email already registered |
| PHARMACY_NOT_VERIFIED | 403 | pharmacy not verified |
| DEMO_DISABLED | 403 | demo accounts disabled |
| INSUFFICIENT_STOCK | 409 | not enough stock |
| ITEM_UNAVAILABLE | 409 | item no longer available |
| REQUEST_CLOSED | 400 | prescription request closed |
| NO_PHARMACIES_IN_SCOPE | 422 | no verified pharmacies in target scope |
| RESERVATION_STATE | 409 | reservation in wrong state |
| CONCURRENT_UPDATE | 409 | lock/optimistic-lock conflict, retry |
| DATA_CONFLICT | 409 | other integrity violation (still referenced) |
| INTERNAL_ERROR | 500/502 | unexpected or mail failure |
| ACCOUNT_SUSPENDED | 403 | reserved (Task 5, no handler yet) |
| RATE_LIMITED | 429 | reserved (Task 7, no handler yet) |
